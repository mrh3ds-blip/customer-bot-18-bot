# نرجس

این ربات به صورت خودکار توسط ربات‌ساز ساخته شده است.

- نوع ربات: ثبت سفارش خدمات
- امکانات: پرداخت کارت‌به‌کارت و تایید رسید، فرم‌ساز و خروجی اطلاعات، پنل مدیریت ساده
- پشتیبانی: پشتیبانی

## پنل مدیریت داخل ربات
ادمین ربات با /start منوی مدیریت را می‌بیند و می‌تواند محصولات/خدمات، متن‌ها، سوال‌های فرم، کارت‌به‌کارت، لینک پرداخت و مرچنت/API درگاه را تغییر دهد.

## نکته پرداخت آنلاین
برای زرین‌پال، پرداخت آنلاین با callback خودکار فعال است. برای سایر درگاه‌ها می‌توان لینک پرداخت عمومی ثبت کرد. Callback: /payment/zarinpal/callback
